#   @<record id> groups the terms searched for that record. Terms include the

# FINDINGS — both change what is placed, and neither is mine to settle
# ===========================================================================
#
# FINDING 1 — Schoff's English and the Greek name different places.
#
#   §54 Greek: τοῖς ἀπὸ τῆς Ἀριακῆς εἰς αὐτὴν ἐρχομένοις πλοίοις
#       "ships coming to it from ARIAKE"
#   §54 Schoff: "abounds in ships sent there with cargoes from ARABIA"
#
#   Ariake is the northern Konkan coast; Arabia is not. Schoff 1912 is
#   translating a different reading, and Casson 1989 prints Ariake. Two more
#   in the same sections: the Greek has Λιμυρική where Schoff has "Damirica",
#   and Τοπαρόν / Τυραννοσβόας where Schoff has "Togarum / Aurannohoas".
#
#   The placement must follow the ORIGINAL, not the reference translation.
#   Ariake and Arabia are a thousand miles apart and would draw a different
#   trade network. This is the Part 6 lesson arriving in W1: chrf_ref treats
#   a published translation as ground truth, and a published translation is
#   itself an edition with readings in it.
#
#   Action: place Ariake, and record the divergence in the entry's note so the
#   next reader does not "correct" it back to Schoff.
#
# FINDING 2 — the Muziris papyrus does not name Muziris.
#
#   The excerpted text names Koptos (twice), Alexandria, and the Ganges
#   adjectivally. It does not name Muziris, Berenike, or the Red Sea port the
#   cargo landed at. "Muziris" is in our title, our notes and the papyrus's
#   conventional name — that is, in editorial prose, not in the source.
#
#   Placing Muziris as this record's focus would be the Vimose defect exactly:
#   a claim carried by our own scaffolding rather than by the text, arriving
#   downstream attached to a citation. The excerpt's subject geography is the
#   Egyptian leg — Koptos to Alexandria.
#
#   Two honest options, and the choice is a curatorial one:
#
#     (a) focus = Koptos, destination = Alexandria, source = Ganges.
#         Places only what the text names. The record then contributes the
#         Egyptian half of the route and no Indian endpoint.
#
#     (b) Extend the excerpt to a passage of SB 18 13167 that does name the
#         Indian port, then place it. The recto names Muziris elsewhere in the
#         papyrus; this record excerpted col. ii lines 2-8 only.
#
#   (b) is the better record and costs a source-recovery pass against
#   papyri.info, the same shape as the Part 3b recoveries. (a) is correct
#   today and can be superseded.
