# BLOCK_G_START — AMENDMENT 1

*Written 2026-09-07, **before Block G runs and with no run in hand.** That timing
is the whole licence for this document. The standing rule is that a gate amended
at the end is a gate fitted to its result; the same applies to an operating
document, and the only safe moment to change one is before the block it
operates.*

**Fold these into `BLOCK_G_START.md` rather than keeping this file beside it.**
One operating document is the project's own pattern, and an amendment kept
separately is an amendment somebody reads second or not at all. Each change below
names the section it belongs in.

# 2. §3 ITEM 4 — THE DEBT TABLE GAINS A "WHEN", AND TWO ITEMS ARE ALREADY SCHEDULED

The sequencing after Block G is settled and Block G should record it rather than
leave a later thread to rediscover it:

```
next, before the UI     FINDINGS 82 and 86, as ONE item — see
                        W3_DECLARE_DONT_INFER.md. Instrument only; no record
                        is curated
then                    the UI: chatbot, map, click-through citation
after the UI            everything else in §5, and pillars 2-4 as open
                        questions
```

So the table wants a third column beside *item* and *owning workstream*: **when**,
with three values only — `next`, `after the UI`, `open`. Block G sorts; it does
not close.

**FINDINGS 82 and 86 enter the table as a single row pointed at W3**, not as two.
They are one defect — inference where a declaration belongs — and splitting them
across two rows is how one gets fixed and the other stays open.

# 4. §2, Q1 — WHICHEVER READING IS TAKEN, PREDICT THE NEXT RANKING RUN

Q1's answer is about to be tested. The next work re-opens a vein that was blocked
and points at roughly six more records, and FINDING 91 already says what that
does: **a fall the size of the pair's existing depth, on the order of three ranks
per hundred per three per cent of index growth, with the pairs at rank 1 or 2
losing nothing.**

Add to §2, under Q1:

> **Whichever reading Block G takes, it writes a prediction for the next
> record-adding run before that run exists** — direction, mechanism, rough
> magnitude from FINDING 91's rate, and **the observation that would falsify it.**
> Block F's practice was five predictions per sub-tranche, each naming its own
> refutation, and its own conclusion was that the two refuted ones were worth
> more than the three confirmed. A verdict about whether ranking survives scale,
> written immediately before six more records land, and *not* accompanied by a
> prediction, is a verdict that will be read afterwards with an explanation
> available for whatever happened. That is FINDING 83.

This costs one paragraph and it is the cheapest thing in the block.

# 7. WHAT THIS AMENDMENT DELIBERATELY DOES NOT ADD

- **No new gate, no new box, no new threshold.** Block G is a decision and not a
  build, and an amendment that gave it something to measure would have made it
  one.

  them did not move.

  session that makes the decision, not filed in advance by the session that
  anticipated it — rulings 20 and 21 have no full text precisely because they
  were left as lines in somebody else's list.
